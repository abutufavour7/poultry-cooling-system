# Solar-Powered Mist Cooling System for Poultry Farms
Supplementary code and data for my final year project: a solar-powered, ESP32-controlled mist cooling system that regulates temperature and humidity in a poultry house.
# What's here
firmware/ — the ESP32 Arduino code

matlab/ — the MATLAB script used to tune the PI controller

data/ — logged test data from the step-response and closed-loop tests
